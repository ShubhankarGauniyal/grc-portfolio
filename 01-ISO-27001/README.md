# ISO/IEC 27001:2022 – ISMS Implementation Portfolio

A practical GRC portfolio demonstrating the design and documentation of an Information Security Management System (ISMS) aligned with **ISO/IEC 27001:2022**.

This project uses a fictional India-based IT services organization, **Spartans Technologies**, to demonstrate key Governance, Risk and Compliance (GRC) activities, including risk management, control implementation, internal auditing and continual improvement.

---

## Project Overview

The objective of this project is to demonstrate how an organization can establish, implement, maintain and continually improve an ISMS using ISO/IEC 27001:2022.

The portfolio covers the following activities:

- ISMS scope definition and organizational context
- Information security risk assessment and treatment
- Statement of Applicability (SoA)
- Information security policies and procedures
- Annex A control implementation planning
- Evidence collection and control assessment
- Internal audit and identification of nonconformities
- Management review
- Corrective action and continual improvement

## Key Case Study Decisions

The fictional organization and its ISMS scenario use the following assumptions and decisions:

| Area | Case Study Decision |
|---|---|
| Organization | Spartans Technologies |
| Location | India |
| Business | IT services and software development |
| ISMS scope | Corporate IT, software engineering, client delivery and cloud operations |
| Risk methodology | 5 × 5 Likelihood and Impact Matrix |
| Risk assessment | 10 identified information security risks |
| Statement of Applicability | 93 Annex A controls assessed: 91 applicable and 2 excluded with documented justification |
| Internal audit | 2 major nonconformities, 2 minor findings and 1 opportunity for improvement |
| Corrective actions | Documented CAPA actions with simulated verification outcomes |


## Disclaimer

This is a fictional, educational case study created for professional learning and portfolio demonstration.

Spartans Technologies, its employees, assets, risks, audit findings, management decisions and evidence scenarios are fictional. Simulated corrective action closure and audit verification do not represent actual organizational implementation or independent audit work.

This portfolio does not establish ISO/IEC 27001 certification, legal compliance or conformity of a real organization. It should not be represented as actual client or employer experience.
